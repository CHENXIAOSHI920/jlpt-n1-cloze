# JLPT N1 完形填空 · 完整版 v2

完整版收录 N1 `問題7 文章の文法` 19 场真题，共 83 个空。2015.07–2019.12 为每套 5 空，2020.12–2026.07 为每套 4 空。页面支持速通版、做题、证据与记录四个模块；学习状态只保存在当前浏览器，不上传服务器。

页面右上角包含与问题四、问题六一致的个人 IP 卡：下一场 JLPT 倒计时、白熊头像、小红书与邮箱均可点击。头像在构建时内联到 HTML，因此线上版和单文件离线版都不需要额外请求图片。

## 运行

修改 `questions.json` 或页面源码后，在本目录运行：

```sh
ruby build.rb
```

也可以直接双击 `index.html` 查看开发版。若需要从原始结构化题库重新生成完整版应用题库，先运行：

```sh
ruby tools/generate_full_library.rb
ruby build.rb
```

构建会校验 19 场真题、83 个空、332 个选项、逐空速通原文、83 张证据卡、332 条选项分析、整篇参考译文和完整版交互门禁，然后一次生成：

- `index.html`：开发预览；
- `分享版/JLPT_N1_Q7_v2.html`：可双击的单文件离线版；
- `发布用/`：可部署的线上目录；
- `../../01_线上版本/GitHub同步版/`：线上同步副本；
- `../../02_上线更新包/N1-Q7-v2/`：完整解压文件、校验值和 ZIP。

## 数据单源

`questions.json` 是应用层唯一题库，按场次倒序保存，默认打开最新的 `2026.07`。构建脚本会对照 `../../真题素材/04_结构化题库/questions.json`，逐场校验文章、空号、选项顺序和答案；构建不会改写原始采集目录。

记录键为 `jlpt-n1-problem7-state-v2`，首次升级会兼容读取旧版 `jlpt-n1-problem7-state-v1`。每种状态分开保存：

- `speedRunSelections`：速通版每题已选选项；
- `latestStatus`：最近一次提交时每空为正确或错误；
- `everWrong`：一旦答错永久保留，直到用户主动重置；
- `starred`：用户主动收藏的重点空；
- `lastEvidenceCardId`：上次查看的闪卡。

离线单文件不注册 Service Worker；`发布用/` 和线上版会注册 Service Worker，当前缓存名为 `jlpt-n1-q7-v2-r1`。更新 HTML 时必须同时更新 `sw.js` 缓存版本。

## 完整版能力

- 19 场真题可通过场次下拉、题目索引或文章底部“上一篇 / 下一篇”切换；
- 每套真题拥有独立的当前作答、检查答案状态和速通进度；
- 当前作答未检查答案时统一显示淡紫色；检查后才用绿色表示正确、红色表示错误，并显示本套正确题数；
- 题目索引按场次分组，速通版与真题模式各自统计正确、错误、未做；
- 速通版每题只显示决定答案的关键原文与四个选项，可直接查看答案；
- 证据区按本套空数动态展示 4 张或 5 张卡片，卡面直接点击翻面；
- 记录页汇总 19 场、83 个空，可按待复习、曾错题和重点筛选，并跨场次回到题目或闪卡；
- 已完成的一轮在下次进入时重置，最近结果、曾错历史和星标保留；
- 标准答案先写正确项，再给判断依据，最后按 1–4 解释每个选项的语法作用与边界；
- 三场源数据存在待复核问题，页面会明确提示，不以猜测覆盖原文。

## 内容风险

以下场次保留源数据并显示校订提示：

- `2018.07`：第 42 题一项选项在原站被截断为「やっ」；
- `2020.12`：整篇来自图片 OCR，仍有个别错字；
- `2023.12`：第 41 题第 3 项原文疑似采集异常。

除 `2026.07` 的人工精修内容外，其余场次的标准答案与逐项说明基于源站判断依据、选项释义和逐空译文生成；正式对外发布前仍建议结合题图复核上述三场。
